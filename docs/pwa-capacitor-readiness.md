# PWA and Capacitor Readiness

## What Was Prepared

- The Vite React app is configured as an online-only PWA.
- The manifest, theme color, favicon, Apple touch icon, and installable app icons are public assets.
- The service worker is generated by `vite-plugin-pwa` with conservative precaching.
- `/Games` static iframe pages are not eagerly precached and are excluded from service worker navigation fallback.
- API, auth, wallet, support, gameplay, and hub calls are not runtime-cached.
- The React app has a global online-only guard that blocks the route tree when the browser reports the device is offline.
- API URLs are centralized behind `VITE_API_BASE_URL`.
- `VITE_HEALTHCHECK_URL` is optional and should point to `https://api.xgame.game/api/HealthCheck` in production.
- Without a configured healthcheck URL, global blocking is based only on true browser offline state; normal API/server failures are handled by each feature.
- With `VITE_HEALTHCHECK_URL` configured, the app checks for HTTP 2xx and JSON `status: "Healthy"` before rendering or unblocking.
- Mobile shell sizing uses dynamic viewport height and safe-area insets where the installed PWA needs them.
- Capacitor Android and iOS projects have been added for manual native testing. See `docs/capacitor-manual-builds.md`.

## Online-Only Behavior

Local/production env example:

```bash
VITE_API_BASE_URL=https://api.xgame.game
VITE_HEALTHCHECK_URL=https://api.xgame.game/api/HealthCheck
VITE_SUPPORT_HUB_URL=https://api.xgame.game/hubs/support
```

- Current production uses `https://api.xgame.game/api/HealthCheck` as the optional health endpoint.
- `VITE_HEALTHCHECK_URL` must be set explicitly; the app does not invent or append `/health`.
- When `VITE_HEALTHCHECK_URL` is empty, the global blocker appears only when `navigator.onLine` is `false` or the browser fires an `offline` event.
- When the browser comes back online, the app unblocks without calling a health URL.
- When `VITE_HEALTHCHECK_URL` is configured, startup, retry, online events, and foreground visibility checks call the endpoint with `GET`, `cache: "no-store"`, and a 5 second timeout.
- A non-2xx response, failed request, timeout, invalid JSON, or JSON status other than `"Healthy"` shows the full-screen service unavailable blocker.
- API, auth, wallet, support, and game failures remain local feature errors unless the browser/device is truly offline.

## Workbox Rules

- `globPatterns` precache only `index.html`, `favicon.ico`, `apple-touch-icon.png`, built `assets/*.js`, and built `assets/*.css`.
- PWA manifest and icons are added by the PWA plugin for installability.
- `globIgnores` exclude `**/Games/**/*`, `**/*.mp3`, and source maps.
- `runtimeCaching` is empty, so API/auth/wallet/profile/support/leaderboard/game/SignalR responses are not cached.
- `navigateFallback` is `/index.html` for React SPA routes.
- `navigateFallbackDenylist` excludes `/Games`, `/api`, `/hub` or `/hubs`, service worker files, manifest/icons, and URLs with file extensions.
